## Calvin

Full-stack engineer. I build real-time, high-concurrency backends and the front ends that
sit on top of them. Most of my work is on the systems and data side, but I cover the full
stack. Parts of what I've shipped run at six-figure scale.

### Now

- **NexTilt**: a Kotlin Multiplatform NEXRAD Level II weather-radar viewer and analysis
  tool. Pure-Kotlin binary decoder, Skia rendering pipeline, output validated against
  golden reference imagery. Open-source release in preparation.
